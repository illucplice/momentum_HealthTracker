A simple habit tracking application designed to help users build consistency and maintain momentum.

## Features

- Create and manage daily habits
- Track habit completion
- View your progress
- Store data with Supabase
- Clean and responsive interface

## Tech Stack

- React
- Vite
- JavaScript
- Supabase
- CSS
